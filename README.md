# dabei.

Vom Speichern zum Hingehen – mit jemandem.

Web app for the dabei. pilot (PM Bootcamp project by María Hauber Ortiz).

## Stack

- Next.js (App Router), deployed on Vercel → dabei.vercel.app
- Supabase (database + accounts), region EU
- Fonts self-hosted via @fontsource (Inter, DM Serif Display)

## Local development

```bash
npm install
npm run dev
```

Design tokens: see `design/README.md`.
